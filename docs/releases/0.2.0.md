# 0.2.0 — Easier first use

- Open a shelf and choose **Connect to an AI** for Codex, Claude Desktop,
  Cursor, or generic local STDIO configuration using the current archive path.
  Copy and merge the configuration into client settings, then restart the client.
  Pensieve does not change those settings automatically.
- Run `uvx ai-pensieve --demo` to import and search invented ChatGPT/Claude
  exports in a temporary archive. Demo discovery stays within the examples;
  normal window closure cleans them up.
- Follow repaired source-install prerequisites and English/Chinese package
  setup guides. The new connection window is available in both languages.

Upgrade a pipx installation with `pipx upgrade ai-pensieve`. With uv, run
`uvx --refresh ai-pensieve` to refresh a cached installation.
Existing archives keep their locations; this release does not move source files
or introduce a database schema change.

Validation includes 140 tests, four Ubuntu/Windows Python 3.10/3.13 CI jobs,
installed-package checks, and real read-only MCP STDIO. Native GUI flows were
tested on macOS; Windows/Linux GUI and Claude Desktop/Cursor integration remain
unverified. See the [compatibility matrix](../COMPATIBILITY.md).
